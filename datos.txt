UNIPATH - CONFIGURACIÓN DE BASE DE DATOS Y ACTIVACIÓN DE CUENTAS

1. CREACIÓN DE LA TABLA codigos_activacion

Ejecutar el siguiente SQL en la base de datos después de crear la tabla usuarios:

CREATE TABLE IF NOT EXISTS codigos_activacion (
    id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    usuario_id INT UNSIGNED NOT NULL,
    codigo_hash VARCHAR(255) NOT NULL,
    fecha_expiracion DATETIME NOT NULL,
    fecha_verificacion DATETIME NULL,
    intentos TINYINT UNSIGNED NOT NULL DEFAULT 0,
    fecha_creacion DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uq_codigo_activacion_usuario (usuario_id),
    CONSTRAINT fk_codigos_activacion_usuario
        FOREIGN KEY (usuario_id)
        REFERENCES usuarios(id)
        ON DELETE CASCADE
);

4. REQUISITOS DEL USUARIO PARA ACTIVACIÓN

La tabla usuarios debe existir previamente.

El estudiante que va a activar su cuenta debe tener:

- rol = 'estudiante'
- estado = 'pendiente'
- contrasena_hash = NULL
- correo_institucional válido
- carne registrado
